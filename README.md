# CoursePilot

CoursePilot is a Python application that generates personalized
practice questions from university course PDFs using Google's
Gemini API.

## Features

- Select and process PDF course materials
- Generate practice questions with customizable difficulty
- Validate AI-generated question data
- Save and load practice sets
- Reveal step-by-step solutions interactively

## Technologies

- Python
- Google Gemini API
- PyMuPDF
- JSON
- SQLite
